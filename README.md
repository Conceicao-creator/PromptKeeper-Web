# 🚀 PromptKeeper — Versão 1.0.1

## 🧠 Gerenciador inteligente de prompts

O **PromptKeeper** é uma aplicação web desenvolvida para organizar, armazenar, pesquisar e gerenciar prompts utilizados com Inteligência Artificial.

O projeto nasceu como uma iniciativa de estudo e foi evoluindo gradualmente, incorporando recursos para facilitar a organização e o acompanhamento dos prompts.

---

## 🎯 Objetivo

O objetivo do PromptKeeper é oferecer um espaço simples e organizado para guardar prompts, permitindo que o usuário encontre, consulte e gerencie seus conteúdos com maior facilidade.

---

## ✨ Principais recursos

### 📝 Gerenciamento de prompts

Permite cadastrar e organizar prompts com informações como:

* Categoria;
* Título;
* Texto do prompt;
* Data de criação.

Também permite editar e excluir prompts.

### 🏷️ Categorias

Os prompts podem ser organizados por categorias, facilitando sua localização e organização.

### 🔎 Busca

O sistema possui recurso de busca para localizar prompts de maneira mais prática.

### 💾 Backup e restauração

O PromptKeeper possui recursos para:

* Criar backup dos prompts;
* Baixar o arquivo de backup;
* Restaurar os prompts posteriormente.

Esse recurso ajuda a preservar os dados do usuário.

### 📊 Dashboard

O sistema possui um dashboard com indicadores relacionados aos prompts cadastrados, incluindo informações como:

* Total de prompts;
* Favoritos;
* Fixados;
* Categorias;
* Prompts criados no dia.

### 📌 Kanban

O projeto também possui uma área de organização em formato Kanban, utilizada para acompanhar informações relacionadas aos prompts.

### 📱 Aplicação Web / PWA

O PromptKeeper possui configuração para funcionamento como aplicação web e suporte a recursos de PWA (Progressive Web App).

---

## 🛠️ Tecnologias

O projeto utiliza tecnologias web, incluindo:

* HTML;
* CSS;
* JavaScript;
* JSON;
* LocalStorage;
* PWA / Web App Manifest.

## 💚 Evolução do projeto

O PromptKeeper foi desenvolvido de forma incremental, passando por diferentes etapas de construção, testes, correções e melhorias.

Durante seu desenvolvimento foram realizados testes de funcionalidades, organização de categorias, armazenamento dos prompts, backup, restauração, busca e apresentação das informações.

A **Versão 1.0 Oficial** representa uma etapa importante dessa evolução.

### Versão 1.0.1

- Correção da atualização imediata da lista de prompts após o salvamento.
- Novo prompt passa a aparecer imediatamente, sem necessidade de atualizar a página.
